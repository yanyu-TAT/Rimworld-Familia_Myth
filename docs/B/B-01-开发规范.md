# 开发规范

> 本文件为项目代码规范详细版。**权威源为 AGENTS.md「强制规范」与「基础代码规范」章节**；**B-04-BUG知识库.md 为反哺源**（修复 Bug 后反哺本文件）。
> 技术栈: C# 10 / .NET Framework 4.7.2 / RimWorld 1.6 / HugsLib / Harmony / Unity

## 一、命名规范

| 元素 | 约定 | 示例 |
|---|---|---|
| 类/接口/方法/属性/事件/枚举成员 | PascalCase | `DevelopableAbility_Magic` |
| 接口 | `I` 前缀 | `IAscendReward` |
| 泛型参数 | `T` 前缀 | `TResult` |
| 私有/内部字段 | `_camelCase` | `_proficiency` |
| 参数 / 局部变量 | camelCase | `statPart` |
| 常量（含 private/internal） | PascalCase | `PlantWorkPerProf` |
| 枚举 | 名词单数（非 flags）；布尔用 `Is/Has/Can` 前缀 | `RewardRarity` |

- 用原语别名声明（`int/float/string/bool`），.NET 类型名仅用于静态成员访问。
- 禁止匈牙利命名、禁止缩写（`Id/Xml/Ftp` 等惯用缩写除外）。
- Mod 框架类命名带统一前缀便于检索：`Patch_*`、`Spell_*`、`Skill_*`、`DevelopableAbility_*`、`Mote_*`、`UI_*`、`StatPart_*`、`QuestNode_*`、`JobDriver_*`、`GameComponent_*`。

## 二、目录结构规范

```
Familia_Myth/
├── About/          # 模组元数据
├── Assemblies/     # 编译输出（只含本模组 DLL + 必需第三方 DLL）
├── Source/         # C# 源码（按职责前缀命名文件）
├── Defs/           # XML 定义（Hediff/Spell/Skill/Thing/Quest/Ritual/…）
├── Patches/        # PatchOperation XML（StatPart 注入、条件补丁）
├── Languages/      # 中英双语本地化（DefInjected + Keyed）
├── Textures/       # 贴图（Aseprite 源 + 导出 PNG）
├── Materials/      # 自定义 shader
└── AssetBundles/   # 资源包
```

- 新功能按「核心类 + 对应 Defs + 对应 Patches + 对应本地化」四件套落位，改动集中。
- `Data/`（原版/DLC XML）与 `decompiledFiles/` 为只读参考，绝不修改。

## 三、错误处理规范

- 只校验系统边界（玩家输入、原版回调、DLC 缺失）；内部代码信任框架保证。
- 异常处理原则：**不空吞**。catch 至少 `Log.Error(msg)`，能恢复则恢复，否则让问题显形。
- Harmony 补丁方法体一律 try-catch，防止单个补丁异常拖垮游戏主线程。
- 返回失败状态时，调用方必须处理失败分支（不静默忽略）。
- 原版 API 可能抛异常的位置（如 `Find.CurrentMap` 为 null）先判空再访问。

## 四、日志规范

- 用 `Log.Message`（信息）、`Log.Warning`（警告）、`Log.Error`（错误），禁止 `Console.WriteLine` 或裸 print。
- 错误日志包含定位信息：触发对象、当前阶段（如 `[Pharna] PawnName 升华失败: ...`）。
- 高频路径（每 tick / 每帧）禁止打日志，避免刷屏。
- 调试用 `DebugSettings`/`Prefs.DevMode` 保护，随功能完成移除。
- 游戏日志统一从根目录 `Player.log` 排查，与模组前缀关键词配合搜索。

## 五、安全规范

- DLC / 其它 Mod 依赖用 `PatchOperationFindMod` / `PatchOperationConditional`（NoMatch 分支）在 XML 层保护，或 `ModsConfig.XxxActive` 在代码层保护（如海之眷顾需 Odyssey）。
- 不提交任何密钥/Token/隐私数据；`Data/`、`lib/`、`Assemblies/` 第三方 DLL、`obj/` 不入库（.gitignore 已覆盖）。
- 不从网上下载执行不明 DLL；引入依赖前确认其来源与版本。
- 资源（Material/RenderTexture/Camera/GameObject）使用后必须释放，避免显存/内存泄漏。

## 六、性能规范

- 帧循环（`DrawAt`/`Tick` 高频路径）避免：LINQ 高频调用、闭包分配、`new` 临时对象、字符串拼接。
- 每 tick 逻辑优先改为每帧/间隔 tick（如 `find.TickManager.TicksGame % N`）。
- 魔法律/魔法弹运动计算保持纯函数，输入确定输出确定，便于复用与测试。
- 大量对象遍历前先缩小范围（map 内 cells / 列表过滤），避免全局 `PawnsFinder` 全量扫描。
- 咏唱词等文本渲染使用相机烘焙为贴图后缓存复用，不在每帧重建。

## 七、技术栈特定规范（C# / RimWorld / Harmony / XML）

### C#（net472 / C# 10）
```
✅ 类型明显时用 var；只读字段用 readonly；常量数字集中为 const
✅ 字符串插值 $""；null 判断 is null / is not null
✅ 集合过滤/转换用 LINQ；简单遍历用 foreach（禁 foreach 中增删）
```

### RimWorld 对象模型
```
✅ 逻辑放进正确的生命周期：Def / Hediff / GameComponent / MapComponent / Mote / WorldObject
✅ 存档持久化数据走 ExposeData()；Def 数据不可在运行期改写
✅ 优先对接原版能力体系（Ability/Verb/Job/StatPart）而非另起炉灶
✅ 需跨存读档保持的运行时状态（如静态集合/运行时注册表）随所属对象 ExposeData 持久化，并在 Load 完成后(PostLoadInit)从可持久化数据重建；勿依赖不参与 Scribe 序列化的 static/非存档字段
✅ AcceptanceReport：返回字符串(含空串)即「不接受/禁用」；表示接受用 return true
```

### Harmony
```
✅ [HarmonyPatch(typeof(X), nameof(X.Member))] + 类内 static 方法 + [HarmonyPrefix]/[HarmonyPostfix]
✅ 重载方法写明参数类型数组；Prefix 返回 false 跳过原方法；Postfix 用 ref __result 改返回值
✅ 补丁体 try-catch；改动原版前先反编译确认原签名
```

### XML（Defs / Patches）
```
✅ 引用类名带命名空间前缀（如 <li Class="Verse.HediffDef">）——xml 中类名注意命名空间前缀
✅ defName 全局唯一；ParentName 继承核对父子字段
✅ 条件补丁用 PatchOperationConditional / PatchOperationFindMod（含 NoMatch 分支）
✅ Hediff 的 initialSeverity > 0（避免被默认逻辑立即移除）
```

## 八、AI 高频错误防犯清单

> 基于本模组实际踩坑记录整理，详见 AGENTS.md「八」对应表。新增坑位时补充出现次数。

|---|---|---|---|
| 1 | 凭记忆写原版 API（如 `SetDuration`） | 先反编译核对，不存在的成员直接用字段赋值 | 1 |
| 2 | Harmony 补丁非 static / 签名错 | static + 参数类型数组 | — |
| 3 | 补丁无 try-catch | 包裹 try-catch + Log.Error | — |
| 4 | Mote/纹理/相机资源泄漏 | try/finally 销毁；DrawAt 中重查占位贴图 | 1 |
| 5 | 随机抽取死循环 | 权重耗尽判断 `tt > 0` | 1 |
| 6 | foreach 中增删集合 | 快照 / 反向遍历 | — |
| 7 | Hediff severity=0 被立即移除 | `initialSeverity` 置正 | 1 |
| 8 | XML 类名缺命名空间前缀 / defName 冲突 | 带前缀、全局唯一 | 1 |
| 9 | 魔法数字无出处 | 抽 const 并对齐设计文档 | — |
| 10 | Patch 中访问未初始化 Find 单例 | 判空 + 阶段判断 | — |
