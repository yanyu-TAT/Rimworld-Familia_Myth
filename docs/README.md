# docs — 项目文档体系

> 本目录为 Familia Myth 的规范与知识文档库。权威源为根目录 `AGENTS.md`；Bug 反哺闭环见 `docs/B/B-04-BUG知识库.md`。

## 目录结构

```
docs/
├── A/  项目基准    — 需求与架构（PRD、技术架构、数据库→本模组为游戏状态/数值设计）
├── B/  开发运维    — 开发规范、测试指南、BUG 知识库
├── C/  知识沉淀    — 代码 Wiki、架构详解、项目长期记忆、本地化术语表
├── D/  方案设计    — （按需）新方案设计文档
├── E/  分析优化    — （按需）代码耦合度/性能分析
└── archive/ dev/   — 归档与进行中文档
```

## 使用约定

- 新增规范先入 `AGENTS.md`，再展开到 `B-01-开发规范.md`
- 修复典型 Bug 记录到 `B-04-BUG知识库.md`，根因是规范缺失时反哺 B-01 与 AGENTS.md
- 每个分类目录内 README 说明该目录维护时机
