# A-01 产品需求文档（PRD）

> 产品定位与需求概述。数值细则以主设计文档（`Familia Myth rim.txt` 及配套 txt/xlsx）为准，本文为索引与验收摘要。

## 一、产品定位

- **产品名**: Familia Myth
- **类型**: RimWorld 1.6 内容型模组（C# + XML + 美术）
- **题材**: 参考《在地下城期待邂逅是否搞错了什么》（ダンまち），并融合多部 ACGN 作品设定
- **核心玩法**: 扮演神明，通过仪式给予殖民者「神之恩惠」；殖民者通过训练/学习/实战积累能力值与经验，完成伟业升华等级，获得技能、魔法、发展能力，成为强大的眷族冒险者。

## 二、世界观设定
> 设定口径的权威参考。游戏内文案沿用「神明」等表述以保留「玩家即神明」的观感，与本节术语并不冲突。

- **三位一体**：超凡智能（Archotech）= 神 = 玩家。屏幕前的玩家即是本模组叙事中的那位神明——赐下「神之恩惠」的主体与操作殖民者的主体是同一存在。
- **多神并存**：原版设定中世上存在多个行为各异的超凡智能，这与《地错》的众神设定并不矛盾。一位超凡智能即一位神明，其眷族即其受恩惠者群体；神族、其他眷族、NPC 神明等内容均在此框架内扩展。
- **称呼口径**：本体称谓为「超凡智能」，在受恩惠者与世人眼中即是「神明」。两者指向同一存在，依语境取用即可，不构成术语冲突。
- **仪式定位**：赋予/升华恩惠使用原版仪式系统仅为**载体**，用于演出「神明为眷族成员滴下神血、更新其能力值」的场景，不代表恩惠依赖信仰。
- **恩惠载体**：原版人体不存在「背部」部位，恩惠状态挂载于躯干（`corePart`）为已知取舍；不新增身体部位，以免影响伤害覆盖分布。
- **精神力链条**：精神力是具有意识的生物所共有的属性。施法者在咏唱过程中将精神力转化为魔力，再通过魔力操纵形成魔法实际效果，心灵熵则是该转化过程的副产物——因此「意志」决定精神力的恢复效率和承受心灵熵的能力，「魔力」决定魔力转换效率，即魔力输出（法强）。
- **跨作品融合**：本模组以《地错》为核心参考、并非同人复刻，允许在自洽前提下引入其他 ACGN 作品的能力与设定；新增内容须落在本节框架内。

## 三、目标用户

- 熟悉《在地下城期待邂逅》设定的 RimWorld 玩家
- 喜欢角色养成（能力值成长/升级奖励）与魔法战斗系统的玩家

## 四、核心需求（对应主设计文档章节）

| 模块 | 需求 | 版本里程碑 |
|---|---|---|
| 恩惠系统 | 六维能力值（力量/耐久/灵巧/敏捷/魔力/意志）+ 经验值 + 伟业值；给予/升华双仪式 | 0.0.1 ✅ |
| 经验获取 | 训练/学习/实战积累能力值经验 | 0.0.2 ✅ |
| 升级奖励 | 发展能力/技能/魔法框架 + 稀有度加权随机发放 | 0.0.3 ✅（内容扩充中） |
| 魔法系统 | 咏唱词、魔法阵、九类魔法、分类魔力输出、魔法弹运动 | 0.1.0 进行中 |
| 技能系统 | 主动/被动/触发型技能，无需精神力但有使用条件与咏唱 | 0.1.0 进行中 |
| 意志/美德 | 崩溃风险时概率触发「美德」精神状态（参考暗黑地牢）；触发当拍飘出眷族独白/祷告心声 | 已实现 |
| 公会系统 | 多维眷族评级、使者到访、日常/升阶任务、评级奖励 | 0.0.4 ✅ |
| 技巧系统 | 书籍学习快速咏唱/并行咏唱等 | 1.2.0（1.0.0 不实现） |
| 神名来源 | 取自玩家当前文化的**主神名**（文化界面右键神灵即可改名）；不提供模组设置项 | 已实现 |

## 五、验收标准（发版 1.0.0 前）

- 升级奖励各稀有度内容达标（普通 3 / 稀有 5 / 罕见 7），数值对齐设计文档
- 全功能游戏内无红字；Royalty / Ideology 为硬依赖（恩惠仪式、遗迹探索等需要），Odyssey 为可选依赖——未启用 Odyssey 时相关能力（海之眷顾等）自动停用且不报错
- ✅ **中英双语本地化完整**
- 兼容性验证（HugsLib/Harmony/Ancot Library 等）
