### 升华奖励（抽取与选取）

> 升华时给出 3 张奖励候选、玩家择一获得；奖励身份、权重与选取流程集中在 `AscendHelper.cs`。

| 项 | 说明 |
|---|---|
| 注册表 | 从 `SpellDef` / `SkillDef` / `DevelopableAbilityDef` 自动注册为**元数据**（类型 + 稀有度 + 权重），稀有度权重 Common / Uncommon / Rare = **20 / 10 / 1**；Unique 权重 0，**只登记不入随机池**（留给后续图鉴 / 特殊途径）；由 `[StaticConstructorOnStartup]` 在 Def 与语言加载完成后构建 |
| 抽取 | 候选需满足「权重 > 0 且 `Available` 且未被该恩惠拥有」；加权不重复抽 n 项；**实例化与 `Available` 判定都推迟到抽取时**（`CreateReward`，类缺 Def / 无法实例化即跳过并报错），故 DLC 与运行时条件不会固化在启动那一刻 |
| 判重 | 按 `DefName`（对应 Def 的 defName）比对 `spells` / `skills` / `developableAbilities`，不再用本地化 `label` |
| 确定性 | 抽样包在 `Rand.PushState(pawn × 等级 × 刷新轮次)` 内 → **读档重做仪式得到同一批结果**，"存读档刷奖励"不可用 |
| 保底 | `Hediff_Pharna.ascendsWithoutRare`（随 `ExposeData` 持久化）：罕见权重 ×(1 + 0.5 × 次数)、封顶 5×；按**到手**奖励的稀有度结算 |
| 选取会话 | `AscendRewardSession`：3 张候选、**每次升华 1 次刷新**（次数来源留接口，后续接仪式质量）、卡片可**锁定**（刷新时保留锁定卡位、只重抽未锁定项，排除集 = 锁定卡 ∪ 上一批卡片）；刷新结果不足时整体回滚，卡列表不会为空 |
| 弹窗 | `Dialog_AscendReward`：卡片左侧独立锁定栏（◆/◇ + 悬停提示）、底部刷新按钮（不可刷新时隐藏）；点卡即获得并关窗 |
| 未采纳 | 类型配额（保证三类各一张）与按恩惠等级分池——**已裁决不做** |
| 池分布目标 | 技能 / 魔法各 **3 / 5 / 7**、发展能力 **5 / 5 / 5**（合计 45 项）；现状技能 3/4/3、魔法 2/3/5、发展能力 5/2/0 = 27 项 |
| 本地化 | `Keyed/UI.xml`（中英对称）：刷新 / 锁定 / 剩余次数提示与锁定标记共 6 键 |
| Debug | `Show Ascend Window`（默认展示全部候选、不消耗刷新）、`Add Acsend Reward`（按注册表逐项直接赋予） |

### 伟业（Feat）

> 伟业由**战斗事实**结算（复用原版 Battle 系统），与任务来源无关；任务侧只发评级升级点数。

| 维度 | 实现 |
|---|---|
| 事件边界 | `Find.BattleLog.Battles`（每 250 tick 扫描；沿 `AbsorbedBy` 取末端；`resolved` 列表去重） |
| 结算时机 | 最后一条日志时间戳 + `Battle.TicksForBattleExit`(5000) 已过 |
| 战斗事实 | 参战者由 `Entries.GetConcerns()` 重建 → 分敌方 / 我方 / 受恩惠参与者 |
| 贡献 | 三路径加权累加：`dealt × 1.0 + taken × 0.5 + support × 1.0`（伤害归因走 `Pawn.PostApplyDamage`；只记我方、只认双方敌对） |
| 分摊分母 | 敌方承受的**全部**伤害（不分来源：我方 Pawn / 炮塔 / 商队 / 陷阱 / 环境）+ 我方承伤折算 + 我方支援；我方 `dealt` 已含在敌方受损内，不重复计入 |
| 支援贡献 | 三来源：`HealHelper` 治疗三工具（治愈 ×1.0 / 包扎与恢复部位 ×0.3）+ `HediffComp_FeatSupport` 持续型效果（XML 配 `<supportPerSecond>`，按实际生效 tick 累计、每 60 tick 上报）+ 时停与光球眩晕按 `ControlPerSecond` 折算；**只计作用于他人者**（嘲讽经 `<allowSelf>` 例外） |
| 性质判定 | 逐 `FeatTraitDef` 调其 `judgerClass` 判定器（方法驱动；阈值写在判定器类内，加性质不改框架） |
| 量度 | `battleMagnitude = threat × Π(性质系数)`；个人 `score = battleMagnitude × share` |
| 档位 | 个人得分过九档阈值表 → `tier 1~9`（阈值待实机标定） |
| 升华 | `AvailableFeat()` 取满足 `tier >= level` 且未使用的**最低档**伟业；用后写 `usedForLevel`（每件伟业每级只能用一次） |
| Debug | `Give Feat`（给鼠标下的角色添加一个 9 档伟业；仅含 `tier`、无战斗数据，页签显示走 `FeatUnknownBattle` / `FeatUnknownPlace` 兜底） |

|---|---|---|---|
| FeatTrait_RepelledAssault | 击退强袭 | 威胁 ≥ 400 且 敌 ≥ 3 | ×1.2 |
| FeatTrait_AgainstTheOdds | 以寡敌众 | 威胁 ≥ 800 且 敌 ≥ 6 且 我方参战 ≤ 3 且 战果 ≥ 3 | ×1.4 |

### 恩惠页签（ITab_Pawn_Pharna）

Pawn 级「恩惠」页签（**仅持有恩惠者可见**，与健康 / 需求等并列），覆盖四个分区：

| 分区 | 内容 |
|---|---|
| 基础能力值 | 角色全名 + 等级与经验抬头 + 六维（名称 / 暖金评级 / 浅灰数值 / 进度条 + 升华门槛刻度），偶数行交错底色；进度条随增速衰减由白转暖色（`GetGrowthDecay`），**铭刻项改用亮金 `Inscribed` 免衰减条**；行 tooltip 给出当前 / 潜在 / 总计与成长效率，铭刻项追加「已铭刻」说明 |
| 发展能力 | `★ 名称 + 品质档位 + 熟练度文本 + 熟练度条`，按**稀有度**着色，偶数行交错底色 |
| 技能 / 魔法 | 左右两栏，条目只显示前缀（`✦` / `✧`）与名称，按**稀有度**着色（不显示冷却 / 充能；不做行交错） |
| 伟业 | 按 **tier** 九档着色；未使用 = 原底 + 亮色条，已使用 = 档位色淡填充 + 半透明色条；三行 = 档位·性质 / 战斗名 / 时间·地点（名称为结算时快照的原版战斗名，缺失时显示「未知战斗」）；tooltip = 战斗总得分 / 个人贡献与个人得分 / 各性质系数 |

- 分区卡统一**淡暖金描边（2px）+ 灰黑填充**，标题为**标签框式**（上边框下移至标题中线、标题左内缩并截断该段边框后以纯白 `Medium` 压制，无标题底色）；条目卡不描边，只靠底色与左侧色条区分；正文与条目字号为 `Small`；
- 发展能力行与技能 / 魔法小卡均带 tooltip（名称 + 描述），口径与眷族页奖励卡一致；
- 页签注册：`Patches/ITabs_Pharna.xml` 往 `BasePawn.inspectorTabs` 列表追加 `FamiliaMyth.UI.ITab_Pawn_Pharna`；
- 技能 / 魔法释放与魔力池开关仍在 Gizmo；页签内唯一的写操作是**铭刻选取**，其余为只读展示；
- **铭刻顶栏**：页签右上角给出可用性两态文本（`铭刻可用` / `铭刻不可用`）+ `铭刻` 按钮；**不可用且未在选择模式中时按钮不绘制**（只留文本）。按钮按下进入选择模式，随后点击任意能力行完成铭刻，`取消` 或点击页签外部退出；
- 已铭刻行的左侧色条（`AccentBarW`）、行底（0.10 alpha）与进度条统一用 `UI_Palette.Inscribed` 亮金；六维名称列内缩 `NameIndent(6)` 让开色条，评级 / 数值 / 进度条位置不变。

### 眷族页（历史窗口内）

经 Harmony 把「眷族」页签挂进原版历史窗口（`HistoryTabHelper`），三栏结构：

| 区域 | 内容 |
|---|---|
| 文化图标卡 | 玩家文化图标 + 文化名（区块高度含上下内边距，名称不压出下边框） |
| 分类列表 | 每个评级方向一张卡：分类名 / 当前评级 / 下一级、升级点数进度条、状态提示（可升级 / 已满级 / 进度百分比）；可升级时整卡描边呼吸 |
| 成员列表 | 每个受恩惠者一张卡：头像 + 姓名 + 等级、六维雷达图、奖励卡列表（按稀有度排序） |

- **跳转**：点击成员卡的头像列 → `CameraJumper.CanJump` → `TryJumpAndSelect` → `Find.MainTabsRoot.EscapeCurrentTab()`（与原版历史页跳转同一顺序）；悬停叠白，tooltip「点击跳转」。
- **页签兜底**：`HistoryTabHelper.Usable` 在历史窗口字段缺失、或哨兵值 `99` 被原版枚举占用时停用自建页签并记 `Log.Error`，绘制 Prefix 放行原版历史页。

### 恩惠身价（对人物财富与难度的影响）

受恩惠者的市场价值随恩惠强度放大，经原版「财富 → 袭击点数」链路抬升难度：

- **注入方式**：`Patches/StatParts_PharnaWealth.xml` 用 `PatchOperationAdd` 把 `FamiliaMyth.Pharna.StatPart_PharnaWealth` 追加到原版 `StatDef[defName="MarketValue"]` 的 `parts` 末尾（先经原版 `StatPart_Health` / `StatPart_Age`）。
- **量度**：等级归一化线性（`level / 10`）、经验归一化 smoothstep（`ExpCap = 30000`），两项各域 ×1..×5（`LevelMaxBonus` / `ExpMaxBonus` 均为 4f），乘积顶点 ×25；非受恩惠者不参与（`pawn.GetPharna()` 为 null 直接返回）。
- **展示**：信息卡 Market value 说明栏两行（`FamiliaMyth.Stat.PharnaWealthLevel` / `...Experience`），文案只含标签，倍数符号与数值由代码拼接。

- **规模**：中英各 **45 个文件**（Keyed 6 + DefInjected 39），中英**逐键对称**（校验脚本 [5] 双向差集为 0）；脚本口径下的键位规模：Def 文本字段 236 / 任务 TKey 22 / rulesStrings 14 / Keyed 224 / 代码引用键 212
