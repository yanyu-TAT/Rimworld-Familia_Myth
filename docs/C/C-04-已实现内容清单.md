## 一、目录结构

```
Familia_Myth/
├── About/              # 模组元数据（About.xml、preview.png）
├── Assemblies/         # 编译输出（Familia_Myth.dll + 运行所需托管 DLL）
├── Source/             # C# 源码（框架类 + Harmony 补丁）
├── Defs/               # XML 定义（Hediff/Spell/Skill/Thing/Quest/Ritual/…）
├── Patches/            # PatchOperation XML（StatPart 注入等）
├── Languages/          # 中英双语本地化（DefInjected + Keyed）
├── Textures/           # 贴图（Mote/Projectile/UI 图标）
├── Materials/          # 自定义 shader
├── AssetBundles/       # 资源包
└── 11.bat              # 构建清理脚本
```

## 四、美术与本地化现状

### 美术
- **贴图**：Aseprite 工程 + 导出 PNG 覆盖大部分特效与法术/技能图标。
- **着色器**：`IncantationText.shader`（咏唱词）、`KingsSword.shader`（王者之剑）；`.shader` 需在 Unity 中手动打包为 AssetBundle 才会生效（见 C-03）。

### 本地化（中英双语，已全量完成）
- **目录结构**：
  - `Keyed/`（代码内文本）4 个文件：`FamiliaMyth.xml`（核心：能力值/恩惠/仪式/美德）、`Quests.xml`（任务全量）、`Abilities.xml`（技能/魔法/发展能力）、`UI.xml`（界面与属性面板）
  - `DefInjected/`（Def 文本）36 个文件：**文件名与 `Defs/` 下源文件一一对应**（如 `DefInjected/HediffDef/Hediff_Ember.xml` ↔ `Defs/HediffDefs/Hediff_Ember.xml`；同属 `Defs/StatDefs/PharnaStats.xml` 的文本已合并为 `DefInjected/StatDef/PharnaStats.xml` 一份）
- **规模**：中英各 **40 个文件**（Keyed 4 + DefInjected 36），中英**逐键对称**（校验脚本 [5] 双向差集为 0）；脚本口径下的键位规模：Def 文本字段 226 / 任务 TKey 24 / rulesStrings 14 / Keyed 193
- **四条文本路径**（细则与取证见 C-03）：Def 字段→`DefInjected`；`rulesStrings`→`DefInjected` 整表替换；任务节点 `SlateRef` 文本→Def 元素加 `TKey` + `<DefName>.<TKey>.slateRef`；代码内文本→`Keyed` + `"Key".Translate()`
- **术语基准**：`docs/C/C-06-本地化术语表.md`（含固定译名、风格要求、译名取舍记录）
- **译名取舍**：保留项目自定拼法 `Pharna`（恩惠）/ `Exploits`（伟业值），未采用原作社区通用的 `Falna` / `Excelia`
- **校验工具**：根目录 `12-本地化检查.ps1`，7 项（Def 文本覆盖 / TKey / rulesStrings / 错误 key 占位 / Keyed 中英差集 / 代码内 Translate 键 / XML 类型引用可解析性）
- **已知取舍**：`Spell_TheWorld.label`（The World）与若干英文原名按原作保留；非中英语言暂无语言包，可由社区补本地化补丁
