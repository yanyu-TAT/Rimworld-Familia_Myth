# C-02 架构详解

> 关键系统架构与决策记录。新增系统或重大调整时更新。

## 一、总体分层

```
Defs/Patches(XML 定义与条件注入) ←→ Source(C# 逻辑) ←→ Languages(本地化)
        ↓                                  ↓
    原版能力体系(Ability/Verb/Job/StatPart/Hediff) + Harmony 补丁
        ↓
    Unity(IMGUI/TextMeshPro/CoreModule) + 自定义 Mote 特效
```

## 二、核心系统

### 恩惠（Hediff_Pharna）
- `Hediff_Level` 子类承载六维能力值 + 潜在值 + 经验/伟业值。
- 升级条件：任一项能力值 ≥ 500（D 级）且伟业值 999。
- 升华：潜在值保留、能力值清零、伟业值清零、等级 +1，并在仪式中发放升级奖励。

### 升级奖励（AscendHelper）
- `IAscendReward`（RewardType：发展能力/技能/魔法；RewardRarity：Common/Uncommon/Rare/Unique）。
- 从 `DefDatabase` 自动注册，按稀有度加权（20/10/1/0）不重复抽取，`tt > 0` 防死循环。

### 魔法（Spell : Ability）
- 复用原版灵能（Psyfocus/熵）与技能栏；`SpellDef` 定义咏唱词/魔法阵层/稀有度/分类。
- 咏唱流程：verb 咏唱 → 逐行咏唱词（Mote_Incantation 相机烘焙）→ 魔法阵展开（Mote_MagicCircle）→ 释放。
- 魔力输出：基础 `SpellPower` + 按 SpellType 分类的 `SpellPower_Attack/Heal/...`，经 `StatPart_SpellPower` 过滤注入，`GetCurrentSpellPower()` 统一取值。
- 魔法弹：`BaseMagicMissileState` 纯运动学积分器（位置/速度/加速度/限幅），状态机切换多段轨迹。

### 技能（Skill）
- 主动/被动/触发三类；Skill 抽象基类 + SkillDef（maxCharge/cooldown/duration/checkInterval）。
- 充能机制：charge（当前可用次数，0..maxCharge 夹取）+ cooldownTimer（回充倒计时）替代单冷却闸。
  常态被动不跑冷却；充能未满且不在冷却时启动回充，冷却结束回一充；释放成功消耗一充。支持多段/击杀重置类技能。
- 效果生命周期：Skill.active 标志 + HediffComp_SkillInEffect（挂在效果 Hediff 上的 comp）。
  效果 Hediff 添加 → CompPostPostAdd → 技能 NotifyEffectStart(active=true)；移除 → NotifyEffectEnd(active=false)。
  active 期间 ShouldCooldown=false，不进入冷却/回充（供嘲讽、余烬等持续效果使用）。
  注意：存读档不触发 CompPostPostAdd/Removed（Hediff 经 ExposeData 恢复），跨存档的运行时集合需在 ExposeData 的 PostLoadInit 阶段重建（如嘲讽 Provokers）。
- 状态指示：Hediff_SkillState + HediffComp_SkillState（由 skillDef 反查 pharna.skills 中技能实例，取 Skill.StateText 显示充能/冷却/可适用）。
- 不消耗精神力，但有使用条件与咏唱时间。

### 发展能力（DevelopableAbility）
- 熟练度体系：每 100 熟练度升一档，映射 I~SSS 12 档 Trait。
- `StatPart_DevelopableAbility` 运行时遍历恩惠上能力，按 StatDef 逐项 Factor 修正；系数为常量便于调参。

### 意志/美德
- 受击时概率触发 `MentalState_Virtue`，五种美德（坚定/无畏/专注/勇猛/振奋）各有通用 + 附加效果，内置冷却 `(10-0.001x)` 天。

### 公会
- `GameComponent_FamiliaRankTracker` 存档级追踪多维度评级；使者 Incident 到访 → 对话接任务 → QuestNode/QuestPart 发放升级点数与伟业值；UI_FamiliaPage 展示眷族评级与成员卡。

### 其他辅助系统
- **远程闪避**：`RangedDodgeChance` Stat + `CompRangeAttackDodge` + `Patches_RangedDodge.xml`，兼容 Ancot Library。
- **特效系统**：大量自绘 Mote（魔法阵、爆裂圆环、斩击、刀鞘、目标锁定、时钟、光灵、上浮粒子等）；`MapComponent_Pharna` 负责恩惠相关地图特效。
- **展示用 Stat**：`StatPart_PharnaDisplay`（恩惠状态卡）。
- **伤口/断肢处理**：`HealHelper` 静态工具（治疗预算分配、包扎、缺失部位恢复），供多个治疗类法术复用。

## 三、关键架构决策

| 决策 | 理由 |
|---|---|
| 魔法继承原版 `Ability` 体系 | 复用灵能 UI/技能栏/熵资源，减少重复造轮子 |
| 咏唱词用相机烘焙为贴图 | 可靠渲染文字，避免字体图集 CPU 读取问题 |
| 发展能力用 StatPart 按 StatDef 注入 | 与 Defs 配置对齐，数值系数集中可调 |
| 公会任务用 QuestNode/QuestPart | 与原版任务系统一致，便于扩展新任务类型 |
| 技能用 charge(充能)+回充冷却而非单冷却闸 | 支持多段/击杀重置类技能，展示当前充能数，语义更直观 |
| 技能 effect 生命周期用 HediffComp 回调驱动 active | 由效果 Hediff 存在与否决定冷却暂停，避免运行时手动维护集合 |
| 技能状态指示用基类+comp 反查；魔法用接口默认实现 | 技能状态为普遍需求(都进 pharna.skills 统一框架)，魔法持续展示为少数魔法 → 按普及度分治 |
| 跨存档运行时集合在 ExposeData PostLoadInit 重建 | 静态集合不随 Scribe 序列化，读档后须从可持久化数据(active/hediff)重建 |
| 击退用 GameComponent 逐 tick 位移 + StunFor 禁用寻路 | 原版无位移型击退 API；每 tick 同步 pather(Notify_Teleported resetTweenedPos:false)防闪回，stun 使 PatherTick 短路 |
