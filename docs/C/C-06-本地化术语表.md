## 七、风格要求

- 采用 RimWorld 官方英文的语气：简洁、克制、叙述性；信件文案可有文采但不浮夸。
- **保持占位符与转义原样**：`{0}`、`{1}`、`{BASETEXT}`、`[PAWN_nameDef]`、`\n`、`[resolvedQuestName]` 等一律照抄，不得增删或改动顺序。
- 数值与单位保持原样（`+50%`、`600kg`、`12 天` → `12 days`）。
- 引号使用直引号 `'` / `"`；人名缩写用 `{0}'s`。
- **咒文 / 咏唱词**：按原作意象还原，保留仪式感与节奏，不逐字直译。
- 已有英文的文件**只补缺键**，不要改动已有译文（除非明显错译，需在报告中说明）。

## 八、译名取舍记录

- 项目长期使用 `Pharna` / `Exploits`（非原作社区通用的 `Falna` / `Excelia`）；经确认**保留项目自定拼法**，代码类名 `Hediff_Pharna` 等亦不动。若将来社区提交本地化补丁，可整体替换。
