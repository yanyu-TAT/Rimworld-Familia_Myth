# C-06 本地化术语表与翻译规范

> 中英文本对照的**统一基准**。翻译任何玩家可见文本前先查本表；表中未收录的新术语应先补充到本表再使用。
> 译名来源：项目既有语言文件 + 原作英文社区通用译法（Falna/Excelia 等未采用，见下「译名取舍」）。

## 七、风格要求

- 采用 RimWorld 官方英文的语气：简洁、克制、叙述性；信件文案可有文采但不浮夸。
- **保持占位符与转义原样**：`{0}`、`{1}`、`{BASETEXT}`、`[PAWN_nameDef]`、`\n`、`[resolvedQuestName]` 等一律照抄，不得增删或改动顺序。
- 数值与单位保持原样（`+50%`、`600kg`、`12 天` → `12 days`）。
- 引号使用直引号 `'` / `"`；人名缩写用 `{0}'s`。
- **咒文 / 咏唱词**：按原作意象还原，保留仪式感与节奏，不逐字直译。
- 已有英文的文件**只补缺键**，不要改动已有译文（除非明显错译，需在报告中说明）。

## 八、译名取舍记录

- 项目长期使用 `Pharna`（原作社区通用为 `Falna`）；经确认**保留项目自定拼法**，代码类名 `Hediff_Pharna` 等亦不动。若将来社区提交本地化补丁，可整体替换。
- 伟业原用 `Exploits`，因其在游戏语境中首义为"利用漏洞（exploit a bug）"、玩家易误读，已改为 **`Feat`**（与原作英文社区译法一致）；代码类名、Def 目录与本地化键同步改名。
- 注：原作中的 `Excelia`（エクセリア）是**经验值**，与本项目的「伟业」不是同一概念；本项目的经验值由 `experience` 承担，两者不可混用。
- 六维能力值的**成长方向**定名「**铭刻**」（英文 `Inscription`）。**项目自创术语**——原作无对应系统词，取的是原作核心意象：恩惠本是神以血刻在眷族背上的神圣文字、更新恩惠即重新书写；**恩惠是神刻下的全部，铭刻是神刻下的方向**。弃用候选：「器量」在中文多指气度／心胸，易被误读为心情类属性；「潜力／潜能」与既有的**潜在能力值**（`potential`，恩惠页 tooltip 的「潜在」一项）撞车，不可用。英文取 `Inscription`（兼有刻写与铭文两义），留意与 `Incantation`（咏唱）拼写相近，勿混；英文侧现存唯一同形词是遗迹任务叙事正文里的普通用词 `inscriptions`（`FM_AncientRelic_Description`），非术语、非键名，不构成冲突。
- 「铭刻」自带"刻入即不易更改"的语义，对应**仅升华时可更改**的机制；铭刻项的成长由**经验值**（键 `FamiliaMyth.Experience`／英文 `Experience`）定向灌注喂养，该通道沿用既有译名，**不引入 `Excelia`**（依据见上条注记）。UI 文案建议写作「铭刻方向」或「已铭刻：魔力」，以免与恩惠本体（同为神所刻写）混淆。
