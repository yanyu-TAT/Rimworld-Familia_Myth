# Familia Myth

**在边缘世界寻求邂逅是否搞错了什么？**

> 参考了包括《在地下城期待邂逅是否搞错了什么》在内的大量 ACGN 作品，为 RimWorld 1.6 / 1.7 制作的模组。
> 
> 你将扮演降临下界的神明，通过仪式为殖民者刻下「神之恩惠」，把他们培养成独当一面的眷族冒险者。

| 项目 | 说明 |
| --- | --- |
| 当前版本 | 0.0.5（开发中，筹备创意工坊测试版） |

## 玩法核心

1. **发展眷族**——在文化中选用本模组的「眷族信仰」结构，从此你便是这个眷族的主神。
2. **给予恩惠**——举行「赋予恩惠」仪式，为殖民者刻下恩惠，她们成为你的眷族成员。
3. **积累成长**——每一次锻炼、每一场战斗都会化作六维能力值的经验，受伤、冥想与社交同样计入；单项与六项总和超过阈值后成长会逐渐变慢，如何取舍由你决定。
4. **完成伟业**——经历战斗，系统会依战斗事实评定伟业（以寡敌众、无伤克敌、摧枯拉朽、一夫当关），并寄来一封带战斗解析的信。
5. **升华升级**——任一项能力值达到 D 级（500），且拥有一条档位不低于当前等级的未使用伟业时，举行「升华恩惠」：等级 +1、现有能力值计入潜在值，随后从 3 张奖励卡中择一获得。
6. **晋升评级**——公会按分类记录眷族成绩，升级点数攒够后会派下不可拒绝的强制任务。评级与成员数值卡可在「历史 → 眷族」页面查看。

## 恩惠与六维能力值

六项能力值各提供一组独特加成，且只对相关行为产生成长——想在某一项上有所斩获，就得去做对应的事：

| 能力值 | 主要影响 |
| --- | --- |
| 力量 | 近战伤害、负重能力 |
| 耐久 | 锐器 / 钝器 / 热能护甲、愈合速度、受伤系数、硬直时间、疼痛阈值、休息消耗 |
| 灵巧 | 全局工作速度、近战与远程冷却、瞄准时间、射击精度 |
| 敏捷 | 移动速度、近战闪避、远程闪避 |
| 魔力 | 魔力储量上限、魔力转化效率 |
| 意志 | 心灵熵阈值、冥想精神力获取、美德的触发概率与冷却 |

成长来源举例：击倒与击杀敌人、承受伤害与伤口愈合、完成有品质的作品、移动与闪避、产生心灵熵、冥想与社交。恩惠状态挂载在躯干上，可在角色健康栏查看。

能力值 / 发展能力每跨一档会弹出一条提示，恩惠页签的能力条会追赶真实数值并闪一下，让你看得见「刚刚长了多少」。

## 魔法（13）

诺亚治愈、光灵守护、烈焰魔剑、光明之风、灵弓光箭、君王之剑、齐射火标枪、The World、豪雷积雨云、爆裂魔法、重生女神之礼赞、布都御魂、索尔之光。

魔法需要咏唱：咏唱期间逐句浮现咏唱词、逐 tick 消耗魔力并累积心灵熵，伴有无咏唱低频音与逐句吐息；完成、中断各有独立音效。咏唱失败（魔力不足 / 心灵熵将溢出）会在消息栏提示。

## 技能（13）

狂化招乱、吸引仇恨、哀兵必胜、回旋踢、剑雨滂沱、火焰亲和、夹枪冲锋、魔力装填、余烬、居合拔刀气刃斩、超电磁炮、我战我在、正义继巡。

分主动、被动、触发三类：主动技能有充能次数与冷却，被动常驻，触发技能在条件满足时自动发动；均不消耗魔力，但需要达到各自的使用条件。

## 发展能力（10）

魔导、异常抗性、高效循环、治愈、海之眷顾、植生学、矿物学、武器同调、连攻、精愈。

发展能力带独立熟练度，随日常使用慢慢累积并提升档位（★ 数与品质随档位变化），档位越高效果越强。

## 精神力 → 魔力 → 魔法

受恩惠者会持续把原版的精神力（psyfocus）转化为**魔力**，咏唱魔法时消耗魔力，转化与施法都会产生副产物**心灵熵**。角色身上有一条魔力池状态条，右上角的角标可以随时开关自动转化。

悬停魔法图标时，心灵熵条会预览「将增加的熵」、魔力池条会预览「将消耗的魔力」，图标角标附带 `M: <消耗>`。

## 升华奖励

每次升华从 3 张候选卡中择一，卡面按稀有度分为普通 / 稀有 / 史诗。有 1 次刷新机会，刷新前可以锁定想保留的卡片；连续未出史诗时稀有奖励的权重会逐步提高。

抽到的奖励在恩惠页签「技能 / 魔法」「发展能力」两栏查看，稀有度以颜色区分。

## 铭刻

恩惠页签右上角可以选一项「铭刻」：已铭刻的能力值**完全免于成长衰减**，且日常经验会按比例转化为该能力值。每次升华恢复一次铭刻机会，铭刻本身保留。

## 意志与美德

面临精神崩溃或受到伤害时，眷族有一定概率进入「美德」状态（参考《暗黑地牢》）：坚定、无畏、专注、勇猛、振奋五种，各有通用效果与专属强化，其中数种还会给身边的同伴提供加成。触发当拍，角色头顶会飘出眷族的自语或祷告。

## 伟业

伟业由**战斗事实**独立评定，与任务无关：一场战斗结束后，系统以袭击点数为基础，从输出、承伤、支援三个维度计算每名眷族的贡献占比，再叠加战斗层与个人层的性质系数（以寡敌众、无伤克敌、摧枯拉朽、一夫当关），换算为九档得分。

达成时寄来一封伟业信：战斗概况、各方贡献明细、性质加成，以及「是否已满足下一次升华条件」的结论。

## 界面

- **恩惠页签**：挂在角色检视面板，分「能力值 / 发展能力 / 技能·魔法 / 伟业」四区，只看也可用于铭刻选取。
- **眷族页**：挂在原版历史窗口，含文化图标卡、评级进度与成员卡（雷达图 + 奖励列表）。
- **战斗日志**：魔法与技能的施法行、命中行都会进原版日志页签，并配置了专属措辞。
- **设置页**：「实验性内容」开关、「教程」开关，以及六维加成曲线的可视化编辑（拖点 / 加点 / 删点，改动即时生效并随模组设置保存）——这组曲线同时也是一份可自定义的模组强度旋钮。
- **教程信**：首次获得恩惠、首次抽到魔法、首次抽到发展能力、首次触发瓶颈、首次可升华时，各发一封一次性说明信。

## 公会与任务

> **实验性内容，默认关闭**。入口：选项 → 模组选项 → Familia Myth → 实验性内容。

公会使者会到访据点带来日常委托；成绩累积到一定程度后派下**不可拒绝**的强制任务，完成即可晋升评级。现有七类任务：据点清剿（日常 / 强制）、紧急救援、罪犯追捕、遗迹探索、物资押运、难民安置。

完成委托会获得**升级点数**（用于晋升评级）；**伟业**只来自战斗事实，不随任务发放。

## 文化与仪式

- 两个恩惠仪式挂在专属文化结构「眷族信仰」下，创建文化时选择它即可自动获得。
- 你的神名取自**当前文化的主神名**：在文化界面右键神灵即可改名，眷族在信件与祷告中会这样称呼你。
- 该结构固定拥有一位神灵，候选来自七对「名字 + 称号」：赫斯缇雅、阿斯特莉亚、洛基、赫菲斯托丝、芙蕾雅、赫尔墨斯、阿尔特弥斯。
- 只有你当前文化的成员才能担任恩惠仪式的接受者。
- 该结构只对玩家派系开放，NPC 派系的文化中不会出现，眷族信仰只属于你和你的殖民地。

## 环境要求与安装

1. RimWorld 1.6 或 1.7，并启用 **Royalty** 与 **Ideology**（必需）。
2. 订阅并启用 **Harmony**（必需）；启用 **Odyssey** 可解锁部分基于该 DLC 的能力，未启用时相关能力自动停用、不会报错。
3. 将 `Familia_Myth` 文件夹放入 RimWorld 的 `Mods` 目录，在模组列表中启用。
4. 从源码构建：`dotnet build Familia_Myth/Familia_Myth.csproj`（一次产出 1.6 与 1.7 两版，分别直写 `Familia_Myth/1.6/Assemblies` 与 `Familia_Myth/1.7/Assemblies`，由 `LoadFolders.xml` 按游戏版本装载）；构建后建议运行根目录的 `11.bat` 清理多余产物。

## 游玩前须知

- 创建文化时若未选择文化结构「眷族信仰」则无法通过仪式获取及升华恩惠，本模组的绝大多数内容也无法体验；模组会在开局一天后发一封提醒信。
- **恩惠会影响难度**：受恩惠者的市场价值随等级与经验放大（顶点 ×25），经原版「财富 → 袭击点数」链路提高袭击强度。
- 公会任务系统为实验性内容，默认关闭。
- 开发中版本，存档结构仍可能变动。
