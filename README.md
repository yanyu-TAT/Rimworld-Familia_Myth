# Familia Myth

> 参考《在地下城期待邂逅是否搞错了什么》设定的 RimWorld 1.6 / 1.7 模组。
> 
> 你将扮演降临下界的神明，为殖民者刻下「神之恩惠」，将他们培养成独当一面的眷族冒险者。

| 项目 | 说明 |
| --- | --- |
| 当前版本 | 0.0.5 |
| 支持版本 | RimWorld 1.6 / 1.7 |
| 必需依赖 | Harmony、Royalty、Ideology |
| 可选依赖 | Odyssey |
| 语言 | 简体中文 / English |

## 玩法核心

1. **发展眷族**——在文化中选用本模组的「眷族信仰」结构，从此你便是这个眷族的主神。
2. **给予恩惠**——举行「赋予恩惠」仪式，为殖民者刻下恩惠，她们成为你的眷族成员。
3. **积累成长**——训练、工作、战斗、受伤、冥想，各种经历都会化作六维能力值的经验。
4. **完成伟业**——经历战斗，系统会依战斗事实记下伟业（击退强袭、以寡敌众、无伤克敌、绝境克强敌）。
5. **升华升级**——任一项能力值达到 D 级（500），且拥有一条档位不低于当前等级的未使用伟业时，举行「升华恩惠」：等级 +1、能力值清零转入潜在值，随后抽取一份升华奖励。
6. **晋升评级**——公会按分类记录眷族成绩，升级点数攒够后会派下不可拒绝的强制任务。评级与成员数值卡可在「历史 → 眷族」页面查看。

> 能力值存在**瓶颈期**：单项超过 400、六项总和超过 2000 之后，同样的经历换来的成长会逐渐变少——专精两三项，还是六项齐头并进，由你决定。

## 恩惠与六维能力值

| 能力值 | 主要影响 |
| --- | --- |
| 力量 | 近战伤害、负重能力 |
| 耐久 | 锐器 / 钝器 / 热能护甲、愈合速度、受伤系数、硬直时间、疼痛阈值、休息消耗 |
| 灵巧 | 全局工作速度、近战与远程冷却、瞄准时间、射击精度 |
| 敏捷 | 移动速度、近战闪避、远程闪避 |
| 魔力 | 魔力储量上限、魔力转化效率 |
| 意志 | 心灵熵阈值、冥想精神力获取、美德的触发概率与冷却 |

成长来源举例：击倒与击杀敌人、承受伤害与伤口愈合、完成有品质的作品、移动与闪避、产生心灵熵、冥想与社交。恩惠状态挂载在躯干上，可在角色健康栏查看。

## 升华奖励

- **魔法（10 种）**：诺亚治愈、光灵守护、光明之风、灵弓光箭、君王之剑、齐射火标枪、The World、豪雷积雨云、爆裂魔法、重生女神之礼赞
- **技能（10 种）**：狂化招乱、吸引仇恨、哀兵必胜、回旋踢、剑雨滂沱、火焰亲和、夹枪冲锋、余烬、居合拔刀气刃斩、超电磁炮
- **发展能力（7 种）**：魔导、异常抗性、高效循环、治愈、海之眷顾、植生学、矿物学

魔法是需要咏唱的「法术」；技能分主动、被动、触发三类，不消耗精神力但有使用条件与冷却；发展能力带独立的熟练度成长，随日常使用慢慢提升档位。

## 精神力 → 魔力 → 魔法

受恩惠者会持续把原版的精神力（psyfocus）转化为**魔力**，咏唱魔法时消耗魔力，转化与施法都会产生副产物**心灵熵**。角色身上有一条魔力池状态条，右上角的角标可以随时开关自动转化。

## 意志与美德

面临精神崩溃或受到伤害时，眷族有一定概率进入「美德」状态（参考《暗黑地牢》）：坚定、无畏、专注、勇猛、振奋五种，各有通用效果与专属强化，其中数种还会给身边的同伴提供加成。触发当拍，角色头顶会飘出一句眷族的自语或祷告。

## 公会与任务

公会的使者会定期到访你的据点，带来日常委托；成绩累积到一定程度后，会直接派下**不可拒绝**的强制任务，完成即可晋升评级（当前为「探索类 · I / II / III 级」）。

完成委托会获得**升级点数**（用于晋升评级）；**伟业**只来自战斗事实、由系统独立评定，不随任务发放。

## 文化与仪式

- 两个恩惠仪式挂在专属文化结构「眷族信仰」下，创建文化时选择它即可自动获得。
- 你的神名取自**当前文化的主神名**：在文化界面右键神灵即可改名，眷族在信件与祷告中会这样称呼你。
- 该结构固定拥有一位神灵，候选来自七对「名字 + 称号」：赫斯缇雅、阿斯特莉亚、洛基、赫菲斯托丝、芙蕾雅、赫尔墨斯、阿尔特弥斯。
- 只有你当前文化的成员才能担任恩惠仪式的接受者。
- 该结构只对玩家派系开放，NPC 派系的文化中不会出现，眷族信仰只属于你和你的殖民地。

## 环境要求与安装

1. RimWorld 1.6 或 1.7，并启用 **Royalty** 与 **Ideology**（必需）。
2. 订阅并启用 **Harmony**（必需）；启用 **Odyssey** 可解锁部分基于该dlc的能力，未启用时相关能力自动停用、不会报错。
3. 将 `Familia_Myth` 文件夹放入 RimWorld 的 `Mods` 目录，在模组列表中启用。
4. 从源码构建：`dotnet build Familia_Myth/Familia_Myth.csproj`（一次产出 1.6 与 1.7 两版，分别直写 `Familia_Myth/1.6/Assemblies` 与 `Familia_Myth/1.7/Assemblies`，由 `LoadFolders.xml` 按游戏版本装载）；构建后建议运行根目录的 `11.bat` 清理多余产物。

## 游玩前须知

- 创建文化时若未选择文化结构「眷族信仰」则无法通过仪式获取及升华恩惠，本模组的绝大多数内容也无法体验。

## 本地化

支持简体中文及由ai翻译的英文。其他语言暂无语言包，欢迎社区补充。
